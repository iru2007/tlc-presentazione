# Carta d'identita digitale

Sito statico in HTML, CSS e JavaScript pensato come presentazione a slide per una spiegazione orale di 4-5 minuti.

## Come aprirlo

Apri `index.html` nel browser.

## Controlli

- Pulsante `Presenta` per lo schermo intero
- Freccia destra per andare avanti
- Freccia sinistra per tornare indietro
- Pulsanti `Avanti` e `Indietro`
- Swipe su smartphone
